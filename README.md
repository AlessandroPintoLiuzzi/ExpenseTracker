# ExpenseTracker

A dedicated mobile solution for travelers to manage their spending on the go, organized by travel "Missions".

## Features
*   **Mission Management:** Organize expenses by specific trips with start and end dates.
*   **Expense Categorization:** Log expenses under Transport, Food, and Hotel.
*   **Receipt Scanning:** Capture and store digital copies of physical receipts using CameraX.
*   **Mission Dashboard:** Clear overview of total spending and history per mission.
*   **Material 3 UI:** Modern, vibrant design with full dark mode support.

## Tech Stack
*   **Language:** Kotlin
*   **UI:** Jetpack Compose (Material 3)
*   **Database:** Room (via KSP)
*   **Camera:** CameraX
*   **Image Loading:** Coil
*   **Navigation:** Jetpack Navigation Compose
